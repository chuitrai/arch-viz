# Architecture Visualizer

Deeply analyze and visualize your project structure directly in VS Code.

## Quick Start
1. Open this project in VS Code.
2. Run `npm install` (if not already done).
3. Press `F5` to start debugging.
4. In the new window, run the command `Visualize Project Architecture`.

## Technologies
- **TypeScript**: Backend logic for filesystem analysis.
- **HTML5 Canvas**: High-performance rendering for project graphs.
- **Physics Engine**: Custom force-directed graph implementation for dynamic layouts.
- **Glassmorphism UI**: Modern, premium aesthetics.
